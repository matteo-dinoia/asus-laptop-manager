# Asus Laptop Manager
A rust wrapper CLI to easily use multiple tool for asus laptop .

## Images
```sh
matteo@arch ~$ asus help
To change it use the following options
- asus fan <option>
        - quiet[/Q/1]
        - balanced[/B/2]
        - performance[/P/3]
- asus gpu <option>
        - integrated[/Q/1]
        - hybrid[/B/2]
        - nvidia[/P/3]
- asus cpu <option>
        - powersave[/S/1]
        - default[/D/2]
        - performance[/P/3]
- asus status <option>
        - cpu
        - fan
        - gpu
- asus status-id <option>
        - cpu
        - fan
        - gpu
Write 'asus help' to see this page

```
